📊 Conceptos Data & IA del día

💾 Concepto DATA: Semantic Layer (arquitectura/modelado)

Qué es: Una capa de abstracción entre los datos brutos y los consumidores (dashboards, analistas, LLMs) que define métricas, dimensiones y relaciones de negocio en un único lugar. Herramientas como dbt Semantic Layer o Cube implementan este patrón.

Por qué importa como Senior Manager: Elimina la proliferación de métricas inconsistentes entre equipos ("¿tu revenue y el mío son iguales?"). Un Semantic Layer bien gobernado reduce discusiones de datos y acelera la confianza organizacional en los números.

💬 Pregunta para el equipo: ¿Tenemos una definición centralizada de nuestras métricas clave, o cada squad define las suyas de forma independiente?

🤖 Concepto IA: Tool Use / Function Calling (agentes/inferencia)

Qué es: Capacidad de un LLM para invocar funciones externas (APIs, bases de datos, búsquedas web) durante la inferencia. El modelo decide cuándo y qué herramienta usar, interpreta el resultado y continúa razonando. Es la base de los agentes autónomos modernos.

Por qué importa como Senior Manager: Tool Use convierte los LLMs de "generadores de texto" en "actores con acceso al mundo real". Cualquier pipeline de automatización que construya tu equipo depende de esta capacidad. Entender sus límites (alucinaciones al elegir herramientas, loops, latencia) es clave para priorizar arquitecturas agenticas.

💬 Pregunta para el equipo: En nuestros agentes actuales, ¿cómo validamos que el modelo elige la herramienta correcta? ¿Tenemos trazabilidad de cada tool call?
